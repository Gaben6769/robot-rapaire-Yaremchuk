# Мета розробки
Сьогоднішнім завданням було перетворити нашого персонажа з простої рухомої фігури на повноцінного ігрового героя який може отримувати шкоду від небезпечних елементів оточення та відновлювати здоров'я за допомогою аптечок

# Покроковий процес реалізації

# Налаштування стану персонажа Player State
Додав змінні для відстеження стану здоров'я у PlayerController cs maxHealth = 5 максимальний запас та currentHealth поточне значення
Реалізував властивість health тільки для читання щоб інші об'єкти могли дізнаватися рівень здоров'я гравця але не могли змінювати його безпосередньо
Створив універсальний метод ChangeHealth int amount який контролює зміну здоров'я та використовує Mathf Clamp щоб значення не виходило за межі від 0 до maxHealth

# Створення інтерактивної аптечки HealthCollectible
Налаштував імпорт спрайта CollectibleHealth встановив Pixels Per Unit = 64
Додав Box Collider 2D із прапорцем Is Trigger
Реалізував скрипт обробки підйому предмету аптечка спрацьовує лише тоді коли здоров'я гравця не максимальне health < maxHealth
Після підйому аптечка додає 1 HP та знищується за допомогою Destroy gameObject
Зберіг об'єкт як префаб

# Створення зони небезпеки DamageZone та таймер невразливості
Налаштував префаб DamageZone із тригером та увімкненим Auto Tiling
Реалізував нанесення шкоди через метод OnTriggerStay2D
Проблема через те що фізичний цикл Unity спрацьовує 50 разів на секунду гравець втрачав усе здоров'я за мить при контакті із зоною
Рішення додав систему тимчасової невразливості isInvincible та damageCooldown = 2 0s Тепер після отримання шкоди гравець отримує захисний таймер на 2 секунди
Важливе налаштування фізики щоб фізичний рушій не присипляв нерухомого гравця всередині зони шкоди встановив Sleeping Mode = Never Sleep у компоненті Rigidbody 2D персонажа

# Проблеми з якими зіткнувся та їх вирішення

# Баг Аптечки підбиралися навіть коли у робота було 5 5 HP
Фікс Додав додаткову перевірку умовою controller health < controller maxHealth перед викликом ChangeHealth

# Баг Гравець переставав отримувати шкоду якщо просто стояв у зоні шкоди й не рухався
Фікс Змінив режим роботи фізики Rigidbody 2D на Never Sleep

# Баг Скрипти HealthCollectible та DamageZone не знаходили компонент PlayerController
Фікс Перевірив щоб на об'єкті гравця висів саме цей скрипт а також перевірив наявність Rigidbody 2D для коректної обробки тригерів

# Результати тестування

При запуску гри гравець має 5 5 HP
Наступання на аптечку при 5 5 HP не знищує її
Захід у DamageZone зменшує HP на 1 у Консолі відображається 4 5
Повторна шкода не завдається протягом 2 секунд завдяки кулдауну
Підбрання аптечки після отримання шкоди відновлює HP до 5 5 та знищує аптечку зі сцени
